Cara kerja dashboard ini

Data dibaca langsung dari Google Sheet "REPORT RETUR MP" tab Input Return lewat Google Apps Script, dan diperbarui otomatis setiap 60 detik selama halaman dibuka. Baris baru, baik dari menu Input Retur maupun yang diketik langsung di sheet, otomatis ikut terhitung. Periode memakai Tanggal Notifikasi. Kondisi diambil dari kolom Kategori Kondisi; "Rusak" menjumlahkan Rusak Berat dan Rusak Ringan, dan baris yang kosong dihitung sebagai "Belum diisi".

Sambungkan ke spreadsheet

Masukkan URL Web App Apps Script (berakhiran /exec) dan API token dari Script Properties. Disimpan hanya di browser ini.
